# 地理 合格ライン問題集 知識編（Web版）

`index.html` を開くと問題演習ができます（GitHub Pages 対応）。

- **何割目標**：6割／7割／8割／9割／全問から選ぶと、その目標に必要な問題だけを出題
- **採点のしかた**（⚙設定）
  - まとめて採点：選択肢を選んでおき「解答を送信」で解いた問題をまとめて採点・解説表示
  - その場で採点：選択肢を押した瞬間に正解・解説を表示
- 解答記録はブラウザに保存（間違えた問題だけ解き直し可）。ログインするとサーバー（Supabase）にも保存
- **ページの向き**：画面を縦にするとA4縦版、横にするとiPad横版のページを表示（設定で固定も可）
- **書き込み**：✏️でペン・マーカー・消しゴム。その場だけの書き込みで、どこにも保存しない（Apple Pencilはペンのみ／指はスクロール、切替可）
- **印刷**：章ページの「🖨 印刷」から問題・まとめ（A4縦）、解説（A4横）を印刷

## PDFを追加・更新したとき

```bash
python3 tools/build.py <PDFを入れたフォルダ>
```

PDFのタイトル（`第N章_名前_本冊_iPad横.html` / `…_解答解説_iPad横.html`）から章を判定し、
`img/` のページ画像と `data.js` を作り直します（iPad横版を優先、無ければA4版）。
必要なもの：poppler-utils（pdftotext, pdftoppm）、Python3 + Pillow
